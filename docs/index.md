# 程序设计与算法基础

你好！欢迎来到程序设计与算法基础课程！

本课程文档适用于 2026-2027 秋冬学期《程序设计与算法基础》[应晶](https://person.zju.edu.cn/0095096) 的教学班，为零基础的同学提供一些简单的引导。

!!! note
    请注意：这个网页仅供学习参考，不包含课程资料和作业，也不属于课程教学或考核内容，不参与成绩评定。

## 章节简介

- [开发环境安装与第一次编译运行](env/index.md)：如何在自己的计算机中搭建 C 语言开发环境
- [调试技术](debug/index.md)：如何找出所写代码中的错误 (bug)，即 debug
- [编程规范](style/index.md)：如何写出优雅、不容易出错的代码
